# Sheet

API близок к `Modal`: состояние передается через `isOpened`, закрытие через `onClose`, футер через слот `footer`.
Для составного фиксированного заголовка используйте слот `header`: прокручиваться при этом будет
только содержимое панели.

## Props

- `isOpened` — открыта ли панель.
- `onClose` — обработчик закрытия.
- `showCloseButton` — показывает кнопку закрытия.
- `title` — заголовок.
- `description` — описание под заголовком.
- `side` — сторона появления: `top`, `right`, `bottom`, `left`.
- `size` — размер панели: `auto`, `extra-small`, `small`, `medium`, `large`, `full`. Для `top` и `bottom` по умолчанию `auto`, для `left` и `right` — `medium`.
- `mode` — отображение панели: `default` прилегает к краю viewport, `floating` оставляет отступ от краёв и добавляет border со всех сторон.
- `rounded` — скругляет внешний край панели в зависимости от `side`.
- `showOverlay` — показывает overlay и тень панели, по умолчанию `true`.
- `closeOnOverlayClick` — закрывать по клику на overlay.
- `closeOnEscape` — закрывать по Escape.

## Slots

- `header` — произвольное содержимое фиксированного заголовка вместо `title` и `description`.
- `actions` — действия справа от заголовка, перед кнопкой закрытия.
- `default` — прокручиваемое содержимое панели.
- `footer` — фиксированный футер.

## Пример

```vue
<Sheet
  :isOpened="visible"
  :onClose="close"
  title="Настройки объекта"
  description="Измените параметры публикации."
>
  Контент панели

  <template #footer>
    <Button mode="ghost" @click="close">Отмена</Button>
    <Button mode="contrast" @click="close">Сохранить</Button>
  </template>
</Sheet>
```

## Составной заголовок

```vue
<Sheet :isOpened="visible" :onClose="close">
  <template #header>
    <Text typography="label-2" color="secondary">Бронь №4821</Text>
    <Gap :size="1" />
    <Text Element="h2" typography="title-2">30 июля — 2 августа</Text>
  </template>

  Контент панели
</Sheet>
```

## Floating

Используйте `mode="floating"`, когда панель должна визуально отделяться от краёв viewport, как Drawer.

```vue
<Sheet
  :isOpened="visible"
  :onClose="close"
  mode="floating"
  side="bottom"
  title="Быстрое действие"
>
  Контент панели
</Sheet>
```
