# Link

Компонент ссылки с типографикой из `Text`, состояниями и слотами для иконок.

## Props

- `typography?: Typography` — типографика из `Text`, по умолчанию `inherit`.
- `inline?: boolean` — включает inline-режим внутри текста.
- `wrap?: boolean` — включает обычный inline-поток, чтобы длинная ссылка продолжала окружающий текст и переносилась по словам.
- `underlined?: boolean` — показывает подчеркивание.
- `disabled?: boolean` — отключает ссылку, ставит `aria-disabled` и убирает из tab order.
- `enableVisited?: boolean` — включает visited-цвет.
- `mode?: 'inherit' | 'accent'` — цвет ссылки, по умолчанию `accent`. В режиме `inherit` ссылка сохраняет цвет родителя также при наведении, после посещения и в disabled-состоянии; disabled обозначается прозрачностью.
- `Element?: 'a' | 'button' | 'span'` — тег компонента, по умолчанию `a`.

## Slots

- `default` — текст ссылки.
- `iconLeft` — иконка слева.
- `iconRight` — иконка справа.

## Пример

```vue
<Link href="/docs" underlined>
  <template #iconRight>
    <IconExternalLinkOutline />
  </template>
  Документация
</Link>
```

Для длинной ссылки внутри подписи или другого узкого контейнера включите перенос:

```vue
<Link href="/terms" mode="inherit" wrap>
  Публичная оферта и Пользовательское соглашение
</Link>
```
