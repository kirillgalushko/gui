# ItemGroup

`ItemGroup` объединяет связанные `Item` в единый список со скруглением и опциональной общей рамкой.

```vue
<ItemGroup stretched>
  <Item>
    <ItemContent>
      <ItemTitle>Подготовить квартиру</ItemTitle>
    </ItemContent>
  </Item>
  <ItemSeparator />
  <Item>
    <ItemContent>
      <ItemTitle>Проверить санузел</ItemTitle>
    </ItemContent>
  </Item>
</ItemGroup>
```

- `stretched` растягивает группу на доступную ширину.
- `mode="outlined"` (по умолчанию) отображает общую рамку; `mode="plain"` убирает её.
- `separated` добавляет разделитель между соседними `Item`, если между ними не используется `ItemSeparator`.
- Для явного управления разделителями используй `ItemSeparator`.
- В `mode="plain"` прямые дочерние `Item` не имеют горизонтальных внутренних отступов; их вертикальные отступы сохраняются.
