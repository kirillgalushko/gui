# Dropdown

Выпадающее меню или панель, привязанная к trigger-элементу. В GUI trigger остаётся
default-слотом `Dropdown`, а content — слотом `popper`; отдельные обёртки для них не
создаются.

- `stretched` растягивает trigger на ширину родителя.
- `contentWidth="auto"` по умолчанию подбирает ширину панели по содержимому.
- `contentMaxWidth` ограничивает автоматическую ширину произвольным CSS-значением;
  по умолчанию content не выходит за viewport с внешним отступом 8 px.
- Фиксированные пресеты `contentWidth` сохранены: `extra-small` — 260 px,
  `small` — 320 px, `medium` — 420 px, `large` — 520 px.
- `contentPadding` управляет внутренним отступом: `default` — 4 px, `comfortable` — 12 px.
- Содержимое панели передаётся через слот `popper`.

```vue
<Dropdown content-max-width="320px">
  <Button>Открыть</Button>
  <template #popper>
    <DropdownGroup>
      <DropdownLabel>Отображение</DropdownLabel>
      <DropdownCheckboxItem v-model="showStatus">Строка состояния</DropdownCheckboxItem>
      <DropdownCheckboxItem v-model="showPanel">Панель</DropdownCheckboxItem>
    </DropdownGroup>
  </template>
</Dropdown>
```

## Radio group

```vue
<DropdownRadioGroup v-model="position">
  <DropdownRadioItem value="top">Сверху</DropdownRadioItem>
  <DropdownRadioItem value="bottom">Снизу</DropdownRadioItem>
</DropdownRadioGroup>
```

## Submenu

`DropdownSub` открывается при наведении или focus на `DropdownSubTrigger` и остаётся
открытым при переходе указателя на submenu content. После ухода из обеих областей
закрытие выполняется с короткой задержкой, поэтому промежуток между панелями не
схлопывает меню.

```vue
<DropdownSub>
  <DropdownSubTrigger>Поделиться</DropdownSubTrigger>
  <template #popper>
    <DropdownGroup>
      <DropdownLabel>Поделиться</DropdownLabel>
      <DropdownItem>Скопировать ссылку</DropdownItem>
    </DropdownGroup>
  </template>
</DropdownSub>
```

`DropdownList` оставлен как deprecated-алиас `DropdownGroup` для совместимости.
