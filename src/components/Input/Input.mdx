# Input

Базовое поле ввода с поддержкой состояний ошибки, подсказки и adornment-слотов.

## Props

- `autoFocus?: boolean` — фокусирует поле после монтирования.
- `maxWidth?: string` — ограничивает максимальную ширину контейнера.
- `size?: 'extra-small' | 'small' | 'medium' | 'large'` — высота, отступы и типографика как у `Select`, по умолчанию `large`.
- `disabled?: boolean` — отключает поле.
- `postfix?: string` — показывает короткий текст после введенного значения, например валюту.
- `description?: string` — текст подсказки под полем.
- `errorMessage?: string` — текст ошибки под полем.
- `invalid?: boolean` — включает визуальное состояние ошибки.
- `descriptionId?: string` — id для текста подсказки или ошибки.
