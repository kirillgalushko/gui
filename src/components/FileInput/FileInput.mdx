# FileInput

Кнопка выбора одного или нескольких файлов. Компонент скрывает нативный input, поддерживает
`accept`, `capture`, `multiple`, размеры кнопки через `size` и возвращает выбранные `File[]`
через событие `change`.

```vue
<FileInput
  accept="image/*"
  capture="environment"
  label="Добавить фото"
  @change="upload"
/>
```

Для собственного trigger используйте слот `trigger`; он получает `open` и `disabled`. Метод
`open()` также доступен через template ref.

```vue
<FileInput accept="image/*" @change="selectPhoto">
  <template #trigger="{ open, disabled }">
    <Button :disabled="disabled" @click="open">Изменить фотографию</Button>
  </template>
</FileInput>
```
