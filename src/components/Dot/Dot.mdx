# Dot

Компонент рисует декоративную круглую точку.

## Props

- `color: Color` — имя цвета из палитры.
- `shade?: ColorShade` — оттенок палитры от `50` до `950`; по умолчанию `500`.

## Пример

```vue
<Dot color="gray" :shade="300" />
```
