# Hover3d

Универсальная обёртка для лёгкого 3D-наклона содержимого вслед за курсором. Работает с любым содержимым slot: карточкой, кнопкой, аватаром или произвольным блоком. Touch-ввод игнорируется.

## Props

- `maxTilt: number` — базовый максимальный угол наклона в градусах. По умолчанию `7`.
- `scale: number` — базовый масштаб содержимого при наведении. По умолчанию `1.025`.
- `disabled: boolean` — отключает наклон и увеличение.
- `stretched: boolean` — растягивает обёртку на всю ширину родителя.

Сила эффекта автоматически нормализуется по диагонали содержимого: большие блоки получают меньший угол и масштаб, маленькие — немного больший. Поэтому визуальное смещение остаётся примерно одинаковым для карточек, кнопок и аватаров.

## Пример

```vue
<Hover3d stretched :max-tilt="6" :scale="1.02">
  <Card>Содержимое карточки</Card>
</Hover3d>
```
