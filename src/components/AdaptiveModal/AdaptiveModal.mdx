# AdaptiveModal

Обёртка над `Modal` и `Sheet` с единым API. На больших экранах рендерит `Modal`, на мобильных breakpoints из `useViewportBreakpoint` рендерит `Sheet` с `side="bottom"`.

## Props

- `isOpened` — открыто ли окно.
- `onClose` — обработчик закрытия.
- `showCloseButton` — показывает кнопку закрытия.
- `title` — заголовок.
- `modalProps` — уникальные props для `Modal`.
- `sheetProps` — уникальные props для мобильного `Sheet`; `side` остается внутренним и всегда равен `bottom`.

## Пример

```vue
<AdaptiveModal
  :isOpened="visible"
  :onClose="close"
  showCloseButton
  title="Редактировать объявление"
  :sheet-props="{ size: 'full' }"
>
  Контент

  <template #footer>
    <Button mode="ghost" @click="close">Отмена</Button>
    <Button mode="contrast" @click="close">Сохранить</Button>
  </template>
</AdaptiveModal>
```
