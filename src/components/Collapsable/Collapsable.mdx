# Collapsable

Одиночная раскрываемая секция с заголовком и тематической иконкой. По умолчанию
секция открыта.

```vue
<Collapsable title="Данные бронирования">
  <template #icon>
    <IconCalendarOutline />
  </template>

  Содержимое секции
</Collapsable>
```

- `v-model` управляет состоянием раскрытия.
- `default-opened` задаёт начальное состояние без управляемого `v-model`.
- `disabled` блокирует изменение состояния.
- Слот `icon` предназначен для иконки заголовка.
