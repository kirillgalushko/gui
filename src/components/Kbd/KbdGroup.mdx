# KbdGroup

`KbdGroup` располагает несколько `Kbd` в одну строку для отображения сочетания клавиш.

```vue
<KbdGroup aria-label="Открыть командную палитру">
  <Kbd>Ctrl</Kbd>
  <span aria-hidden="true">+</span>
  <Kbd>K</Kbd>
</KbdGroup>
```

- Используй `Kbd` для каждой отдельной клавиши.
- Для знаков `+`, `/` и других разделителей добавляй обычный текстовый элемент между клавишами.
