# Filters

Высокоуровневая композиция для добавления, изменения и удаления активных
фильтров. Состояние хранится во внешнем `v-model`, а список доступных полей
передаётся через `fields`.

```vue
<Filters v-model="filters" :fields="fields" size="small" mode="outline" />
```

Поле задаёт собственные `operators`, `options`, тип значения, `formatValue`
и при необходимости `isValueEqual` для объектных значений. Повторные фильтры
одного поля по умолчанию объединяются; для независимых экземпляров включите
`allow-duplicate-fields`.

`item-layout="compact"` скрывает у активных фильтров название поля и оператор,
оставляя выбранное значение и кнопку удаления. Для смешанного набора задайте
`itemLayout: "compact"` только нужным полям.

Кнопка общей очистки учитывает только фильтры из переданного `fields`. Фильтры,
которыми управляет другой компонент и которых нет в `fields`, не показывают
кнопку и сохраняются при очистке.

`show-menu` и `show-items` позволяют разнести кнопку добавления и строку активных
фильтров по разным частям интерфейса, сохранив один общий `v-model`.

Тип `date` использует стандартный `DatePicker` и хранит выбранное значение как
`Date`. По умолчанию доступны операторы «в дату», «начиная с» и «до даты».
