# FilterMenu

Меню добавления фильтра. Поля с `options` автоматически получают вложенное
меню значений, остальные эмитят `select` сразу. Слоты `trigger`, `field` и
`option` позволяют заменить отображение без изменения схемы данных.
`close-on-select` управляет закрытием меню после выбора.

```vue
<FilterMenu :fields="fields" @select="addFilter" />
```
