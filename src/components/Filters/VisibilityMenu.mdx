# VisibilityMenu

Управляемое меню показа и скрытия элементов. `v-model` содержит ключи
видимых элементов, а `min-visible` не позволяет скрыть обязательный минимум.
Ширина меню по умолчанию определяется содержимым; `content-max-width` позволяет
ограничить её CSS-значением.

```vue
<VisibilityMenu
  v-model="visibleColumns"
  :items="columns"
  label="Колонки"
  content-max-width="320px"
/>
```
