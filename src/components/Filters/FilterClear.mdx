# FilterClear

Кнопка сброса всех фильтров. Поддерживает общий API внешнего вида GUI:
`size`, `mode`, `disabled`; `icon-only` оставляет только доступную иконку.

```vue
<FilterClear label="Очистить фильтры" @clear="filters = []" />
```
