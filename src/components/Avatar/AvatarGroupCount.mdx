# AvatarGroupCount

Показывает количество скрытых участников внутри `AvatarGroup` в формате
`+N`. Наследует `size` и `shape` группы и поддерживает визуальные пропы
`Avatar`: `mode`, `color`, `size`, `shape`.

```vue
<AvatarGroupCount :count="3" aria-label="Ещё три участника" />
```
